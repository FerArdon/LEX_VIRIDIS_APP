
PROCEDIMIENTO DE GESTIÓN DE LICENCIAS - LEX VIRIDIS
===================================================

Este módulo permite generar y validar licencias de uso para el software LEX VIRIDIS.

TIPOS DE LICENCIA SOPORTADOS:
-----------------------------
1. PRUEBA (Trial)      - 15 días
2. MENSUAL             - 30 días
3. SEMESTRAL           - 180 días (6 meses)
4. ANUAL               - 365 días (1 año)
5. PERMANENTE          - 100 años (De por vida)

CÓMO GENERAR UNA LICENCIA:
--------------------------
1. Abra la carpeta "LEX_VIRIDIS_LICENCIA".
2. Ejecute el archivo "GENERAR_LICENCIA.bat" (o ejecute `python license_system.py` desde terminal).
3. Siga las instrucciones en pantalla:
   - Seleccione el tipo de licencia.
   - Ingrese el nombre del cliente (ej: "Bufete Jurídico Pérez").
   - Decida si quiere anclar la licencia al Hardware (PC específica) o dejarla portable.

CÓMO VALIDAR UNA LICENCIA (Para Pruebas):
-----------------------------------------
1. Use la opción 5 en el mismo script.
2. Pegue la clave generada para verificar su validez y fecha de expiración.

INTEGRACIÓN:
------------
Para activar estas licencias en la aplicación principal LEX VIRIDIS, se debe integrar el módulo `license_system.py` en `main_flet.py` para pedir la clave al inicio.
(Actualmente este módulo genera las claves, la integración en la app principal es el siguiente paso si lo desea activar).
