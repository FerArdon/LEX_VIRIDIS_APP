 Mezcla de niveles de abstracción: 
_render_library_view
 hace consultas SQL directas (cursor.execute) mezcladas con creación de controles UI (ft.Container).
 God Object: self se usa como bus de datos global. self.engine, self.auth, self.gemini son accesibles desde cualquier método de UI.
 Lógica de inicialización pesada: 
_load_backend
 conoce demasiados detalles sobre cómo construir todo el sistema.
