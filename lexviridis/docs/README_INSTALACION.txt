¡Bienvenido a LEX VIRIDIS!

LEX VIRIDIS es una aplicación especializada en la búsqueda y consulta de 
legislación ambiental hondureña. Esta herramienta ha sido diseñada para 
abogados, estudiantes de derecho, funcionarios públicos, consultores 
ambientales y cualquier persona interesada en el marco legal ambiental 
de Honduras.

CARACTERÍSTICAS PRINCIPALES:
============================

🔍 MOTOR DE BÚSQUEDA AVANZADO
   - Búsqueda por palabras clave en más de 52,745 términos indexados
   - Búsqueda de frases exactas
   - Operadores lógicos (AND, OR)
   - Resultados ordenados por relevancia

📄 VISOR DE PDF INTEGRADO
   - Resaltado automático de términos de búsqueda
   - Navegación directa a la página específica
   - Apertura con visor nativo del sistema

📚 BASE DE DATOS LEGAL COMPLETA
   - 164 documentos legales ambientales
   - 6,782 páginas procesadas
   - Leyes, decretos, acuerdos y reglamentos
   - Actualizada a 2025

🖥️ INTERFAZ MODERNA
   - Diseño intuitivo y profesional
   - Tema optimizado para trabajo legal
   - Compatibilidad con Windows 11

⚡ RENDIMIENTO OPTIMIZADO
   - Sistema de caché inteligente
   - Búsquedas ultrarrápidas
   - Gestión eficiente de memoria

REQUISITOS DEL SISTEMA:
======================

MÍNIMOS:
- Windows 10 (64-bit) o superior
- 4 GB de RAM
- 500 MB de espacio libre en disco (instalación mínima)
- 3 GB de espacio libre en disco (instalación completa)

RECOMENDADOS:
- Windows 11 (64-bit)
- 8 GB de RAM o más
- 5 GB de espacio libre en disco
- Procesador de 2 GHz o superior

OPCIONES DE INSTALACIÓN:
=======================

INSTALACIÓN COMPLETA (Recomendada):
- Incluye toda la base de datos legal (2 GB)
- Funcionalidad completa sin conexión a internet
- Ideal para uso profesional intensivo

INSTALACIÓN MÍNIMA:
- Solo el ejecutable principal (300 MB)
- Base de datos reducida
- Ideal para pruebas o uso ocasional

DURANTE LA INSTALACIÓN:
======================

1. Seleccione el directorio de instalación
2. Elija las opciones de accesos directos
3. Configure las asociaciones de archivos (opcional)
4. Espere a que se complete la instalación

DESPUÉS DE LA INSTALACIÓN:
=========================

- LEX VIRIDIS estará disponible en el menú Inicio
- Se creará un acceso directo en el escritorio (si se seleccionó)
- La primera ejecución puede tomar unos segundos adicionales
- Se creará automáticamente el índice de búsqueda

DESINSTALACIÓN:
==============

Para desinstalar LEX VIRIDIS:
1. Use "Agregar o quitar programas" en Windows
2. O ejecute el desinstalador desde el menú Inicio
3. Opcionalmente, elimine los datos de usuario

SOPORTE TÉCNICO:
===============

Si experimenta problemas durante la instalación:
1. Ejecute el instalador como administrador
2. Desactive temporalmente el antivirus
3. Verifique que tiene suficiente espacio en disco
4. Contacte al equipo de soporte técnico
