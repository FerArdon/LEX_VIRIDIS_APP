📋 INSTRUCCIONES DE DISTRIBUCIÓN:

🎯 PARA ADMINISTRADORES:
1. Distribuir el archivo LEX_VIRIDIS_v1.1.0_Setup.exe
2. Instruir a los usuarios ejecutar como administrador
3. Verificar requisitos del sistema antes de la instalación

🎯 PARA USUARIOS FINALES:
1. Descargar LEX_VIRIDIS_v1.1.0_Setup.exe
2. Hacer clic derecho → "Ejecutar como administrador"
3. Seguir el asistente de instalación
4. Seleccionar opciones deseadas
5. Completar la instalación
6. Ejecutar LEX VIRIDIS desde el menú Inicio o escritorio
